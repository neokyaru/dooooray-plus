# 두레이 플러스 배포 저장소

두레이 플러스 업데이트와 커스텀 이모티콘을 배포합니다. 현재 버전은 **3.8.36**입니다.

- 메시지 검색·파일·사진·영상 목록의 ‘대화로 가기’ 후 이전 위치나 맨 아래로 되돌아가던 스크롤 충돌을 수정합니다. 키보드·미리보기·다운로드 목록의 이동도 인식하며 다른 대화의 읽기 위치는 유지합니다.
- 커스텀 팩 이름이 특수기호로 시작하면 먼저 모으고, 각 그룹을 가나다순·자연수 순으로 정렬합니다. 첫 진입과 새로고침에 적용하며 즐겨찾기 순서·선택 팩·이미지 캐시는 유지합니다.
- 팩별 암호를 입력해야 선택·전송할 수 있는 커스텀 이모티콘을 지원합니다. 해제 상태는 현재 실행에서만 기억합니다.
- 지원되는 동일 출처의 큰 첨부파일을 순차 수신합니다. 서버와 네트워크 속도는 환경에 따라 달라집니다.
- 로딩 실패가 계속되면 Windows 복구창에서 최신 설치 파일 다운로드와 플러스 재실행을 안내합니다. 재실행은 저장 확인 후 진행합니다.

정상 실행 중인 GitHub 업데이트 사용자는 일반 서명 패치로 적용할 수 있습니다. 설치 EXE는 최초 설치/복구용 선택 사항입니다. 기존 설정·다운로드 기록·저장된 이모티콘·정상 확인 버전을 유지합니다.

## 공개 배포 파일

| 경로 | 용도 |
| --- | --- |
| `update/latest.json`, `update/v2/latest.json` | 같은 서명 업데이트 정보 |
| `update/theme-버전.zip`, `update/v2/theme-버전.zip` | 같은 최신 패치 |
| `update/v2/installer.json`, `update/v2/DoorayPlus-버전-Setup.exe` | 최신 설치 정보와 설치 파일 |
| `catalog.json`, `packs` | 커스텀 이모티콘 목록·팩·이미지 |
| `emoticon-index.json` | 이미지가 들어 있는 고정 Git 커밋 |
| `update-public.pem` | 공개 업데이트 검증키 |

게시 시 새 서명과 파일을 검증한 뒤 이전 업데이트 파일을 정리하여 최신 배포 파일 6개를 유지합니다. Git 이력과 이모티콘의 고정 커밋은 보존합니다. 과거 메시지와 즐겨찾기는 당시 이미지의 원본 ref/path를 사용합니다.

## 관리 도구

`script` 폴더와 관리용 CMD는 로컬 전용이며 이 공개 저장소에서 추적하지 않습니다. 관리자는 별도로 받은 도구 ZIP을 저장소 루트에 풀어 사용합니다. 도구 ZIP의 `.gitignore`도 적용하고, `script/README.md`의 안내를 따릅니다.

`update-public.pem`은 GitHub 로그인 인증서가 아닌 공개 업데이트 검증키입니다. 개인 서명키와 GitHub 로그인 정보는 공개 저장소에 저장하지 않습니다.

기존 GitLab 주소만 사용하는 설치본은 마지막 서명 이전 패치 또는 정식 복구 절차를 통해 GitHub 업데이트 주소로 전환해야 합니다. 호스트가 삭제되거나 차단된 경우에는 복구 설치가 필요할 수 있습니다.

이 도구를 사용함으로써 발생하는 모든 문제는 사용자 책임입니다.
